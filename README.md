# 国道走破マップ

走破した区間を CSV に書き足してコマンドを1つ叩くと、走破済み＝赤／未走破＝青で
塗り分けた地図（HTML）が出来上がります。

道路の形状は OpenStreetMap から取ってきて `cache/` に貯めます。
一度取得すればオフラインで何度でも地図を作り直せます。

Python 3.8 以降。追加ライブラリは不要です。

---

## 区間の指定方法

`routes.csv` の「区間」欄に、次の4通りが書けます。粒度は路線ごと・行ごとに混ぜて構いません。

| 書き方 | 例 | 粒度 |
|---|---|---|
| 全線 | `全線` | 路線まるごと |
| 都道府県 | `新潟県` | 県境で区切る |
| 市町村 | `新潟県長岡市` | 市町村界で区切る |
| 交差点 | `宮内〜与板橋` | いちばん細かい |

都道府県名は必ず頭から書いてください（`長岡市` だけでは同名の判別ができません）。
政令指定都市の区も `新潟県中央区` の形で指定できます。

`新潟県/富山県` のようにスラッシュでまとめ書きもできます。

## 最初の1回

```
cd C:\usr_programs\kokudo
python kokudo_map.py init
```

`routes.csv` が出来ます。サンプルなので自分の記録に書き換えてください。

次に全国道の形状を取得します。1〜507号を順に取るので **20〜30分ほどかかります**。
途中で止めても、もう一度同じコマンドを打てば続きから再開します。

```
python kokudo_map.py fetch --all
```

急ぐなら `--all` なしで実行すると `routes.csv` に出てくる路線だけを取ります。
その場合は未走破路線の下地が地図に出ず、走破率も取得済みの路線内での比率になります。

---

## 普段の使い方

```
python kokudo_map.py fetch     ← 新しい区間を書き足したとき
python kokudo_map.py build     ← 地図を作り直す（michinoeki.csv もここで更新されます）
```

`kokudo_map.html` が更新されます。ブラウザで開いてください。

## 交差点で指定する

OSMに登録されている交差点名しか使えないので、まず使える名前を一覧で出します。

```
python kokudo_map.py nodes 351
```

```
国道351号の名前付き地点 6 件（端から順）

  ●     6.1 km  宮内
  ●    62.2 km  中沢
  ●   104.6 km  本町
  ●   176.1 km  与板橋
  ・   219.3 km  川崎
  ●   284.2 km  本町
```

`●` は信号のある交差点、`・` はそれ以外です。
km は路線の端からの距離で、どのあたりの交差点かの目安になります。
全件は `交差点一覧/国道351号.csv` にも出るので、Excelで開いて探せます。

ここに出た名称をそのまま `routes.csv` に書きます。

```csv
351,宮内〜与板橋,2025-06-01,
```

指定した2点の間は、路線のネットワーク上の最短経路として計算されます。
上下線が分離している区間や重複区間があっても、距離は二重に数えません。

### 同名の交差点があるとき

上の例では `本町` が2か所あります。何も書かなければ経路が最短になる組み合わせが選ばれ、
その旨が警告に出ます。意図と違う場合は位置を添えてください。

```csv
351,本町@284.2〜川崎,,     ← 起点から284.2km地点のほうの本町
351,本町@35.3671,137.1049〜川崎,,   ← 緯度経度で指定
```

### 交差点名が見つからないとき

その交差点がOSMに登録されていないだけです。市町村単位に落とすか、
OSMに交差点名を追加してから `cache/nodes/rXXX.json` を消して取り直してください。

## routes.csv の書き方

| 列 | 内容 |
|---|---|
| 路線番号 | `17` / `R17` / `国道17号` のどれでも可 |
| 区間 | 上の4通り |
| 走破日 | 任意。空欄可 |
| メモ | 任意。地図のポップアップに出る |

```csv
路線番号,区間,走破日,メモ
17,全線,2024-05-03,
8,新潟県,2023-08-11,親不知
8,富山県高岡市,2023-08-12,
116,新潟県長岡市,,
351,宮内〜与板橋,2025-06-01,
352,全線,2025-06-20,枝折峠
```

同じ路線を何行に分けても、まとめて1本として集計されます。
全線走破できたらまとめて `全線` の1行に置き換えて構いません。

## 出来上がる地図

- 背景は既定で地理院地図の**白地図**（海岸線と行政界だけ。地名や高速道路は出ません）
- 走破済みは赤、未走破は青。1本の国道の中でも走った部分だけが赤くなる
- 右パネルに距離ベースの走破率、全線走破本数、路線一覧
- 一覧の国道標識（おにぎり）を押すと、その路線だけが色濃く残って他が沈み、
  琥珀色の縁取りが付く。もう一度押すか Esc で解除
- 地図上の線をクリックすると区間・走破日・メモが出る

`kokudo_map.html` は1枚で完結しているので、そのまま誰かに送っても見られます。
（Leaflet と地図タイルはネット経由で読むため、閲覧時はオンラインである必要があります）

### 背景を変える

右パネル上部で、地図を開いたままいつでも切り替えられます。

| 背景 | 中身 |
|---|---|
| 白地図 | 海岸線・行政界・都道府県名・市区町村名のみ（既定） |
| 淡色地図 | 地名や高速道路も入った通常の地図 |
| 標準地図 | 地理院地図の標準表示 |
| 空中写真 | 航空写真 |
| 背景なし | 真っ白。国道の線だけが残る |

「濃さ」のスライダーで背景を薄くできます。白地図でも市区町村名が邪魔なときは
50%くらいまで下げると線が引き立ちます。「未走破の国道も描く」を外すと、
走った道だけが浮かび上がります。

毎回同じ設定にしたいときは `kokudo_map.py` の冒頭を書き換えてください。

```python
DEFAULT_BASEMAP = "blank"   # blank / pale / std / photo / none
BASEMAP_OPACITY = 0.55
SHOW_TODO = True
SHOW_NODES = True
SHOW_EKI = True
```

なお白地図は z5〜z14 でしか配信されていないため、拡大しすぎると輪郭がぼやけます。
市街地を詳しく見るときは淡色地図に切り替えてください。

### 交差点名

「交差点名を出す」を入れて拡大すると、国道上の交差点名が出ます。
ある程度寄らないと出ません（点が z11 から、名前は z13 から）。
名前は重なるものを捨てながら置くので、広く見ているときほど間引かれます。
青い点が信号交差点、灰色の点はそれ以外の名前付き地点です。

名前のうしろに **`R路線番号/端からのkm`** が付きます。
重複区間では乗っている国道をすべて出します。

```
四日町 R290/12.4              国道290号の、端から 12.4 km 地点
日比谷 R1/55.4 R20/39.3       2本が重なる地点
下三栖 R1/?                   路線が分断していて距離を測れなかった地点

県庁前交差点                   3本以上は下に積む
  R32/135.8
  R33/7.1
  R55/36.9
  R56/0.0
```

2本までは名前のうしろに並べ、3本以上は下に積みます。
横に伸ばすと重なり判定で捨てられ、かえって見えなくなるためです。

**交差点名をクリックすると、乗っている国道ごとの距離と、区間欄に貼れる形が出ます。**

```
日比谷  信号交差点
  国道1号    55.4 km   日比谷@55.4
  国道20号   39.3 km   日比谷@39.3
  どの路線でも: 日比谷@35.67512,139.75954
```

同名の交差点があるときは、これを貼れば場所を確定できます。
`@キロ程` はその路線の中でだけ通じる値なので、路線をまたいで使い回さないでください。
迷ったら `@緯度,経度` の方が確実です。

なお km は路線の端からグラフ上を辿った距離で、道路標識のキロポストとは一致しません。
同名の交差点を見分けるための番号だと思ってください。

## 道の駅

国道と同じように、行った道の駅を赤、まだの道の駅を青の丸で地図に出します。

記録は `michinoeki.csv` です。**このファイルは自分で作る必要はありません。**
`build` を実行すると、取得済みの道の駅がすべて書き出された状態で用意されます。

```csv
都道府県,道の駅,訪問日,メモ
新潟県,あがの,2024/5/3,
新潟県,いりひろせ,,
新潟県,クロス10十日町,,
```

**訪問日の欄を埋めた駅が「行った」扱い**になります。日付を覚えていないときは
`○` でも構いません（空欄でなければ訪問済みとみなします）。

新しい道の駅が OSM に追加されると、次の `build` のときに行が足されます。
自分で書いた行が消えることはありません。逆に、CSV にだけ書いた駅
（OSM に未登録の駅など）もそのまま残ります。

地図の丸をクリックすると駅名・都道府県・訪問日・メモが出ます。
右パネルの「道の駅を出す」で表示を切り替えられます。

### 収録数について

道の駅は OSM の `highway=services` / `highway=rest_area` から拾っています。
全国で約1,230駅ありますが、OSM に登録されているのは1,000駅弱です。
足りない駅は `michinoeki.csv` に自分で行を足せば一覧には載ります
（ただし座標が無いので地図には出ません）。

## 走破率の数え方

道路を細かい辺に分解し、走破した辺の集合として管理しています。そのため、

- 県指定と交差点指定が重なっても二重計上されません
- 複数の国道が重複している区間も、全国の総延長では1回だけ数えます
- 「国道8号の47%」のような部分走破率がそのまま出ます

## 調整できるところ

`kokudo_map.py` の冒頭にあります。

- `SIMPLIFY_TOLERANCE` — 線の間引き量。既定 0.0015（約150m）。
  小さくすると精密になりますがHTMLが重くなります。全国道で既定値なら数MB程度です。
- `DEFAULT_BASEMAP` / `BASEMAP_OPACITY` / `SHOW_TODO` — 背景地図の初期表示
- `SHOW_NODES` / `NODE_MIN_ZOOM` / `LABEL_MIN_ZOOM` — 交差点名の初期表示と、
  点・名前が出はじめるズーム。低くすると広域でも名前が出ますが、
  重なり判定で捨てられるぶんが増えるだけであまり読めません
- `OVERPASS_ENDPOINTS` — 取得先のミラー。上から健全なものが選ばれます
- `REQUEST_INTERVAL` / `MAX_INTERVAL` — リクエスト間隔の下限と上限。
  混雑を検知すると自動で上限まで広がり、落ち着くと下限に戻ります。短くしないでください。
- `ATTEMPTS_PER_TARGET` / `MAX_PASSES` / `PASS_COOLDOWN` — 再試行の粘り強さ
- `COORD_PRECISION` — 座標の突き合わせ桁数。既定7。変更しないでください。
- `SHOW_EKI` — 道の駅を最初から表示するか
- `DONE_COLOR` / `TODO_COLOR` / `SELECT_COLOR` — 走破済み・未走破・選択中の縁取りの色。
  未走破を青にしているのは、白地図の市町村界（灰色の細線）と紛れないようにするため
- `GAP_BRIDGE_M` — OSM 上で way が繋がっていない隙間を、何m まで繋いで扱うか。
  既定 50m。行き止まりどうしだけが対象なので、立体交差で接近しているだけの
  道は繋ぎません。0 にすると繋がなくなります

## うまくいかないとき

**特定の路線だけ線が出ない／短い／途切れ途切れになる**
OSM側のリレーションが未整備の可能性があります。
[overpass turbo](https://overpass-turbo.eu/) で
`rel["type"="route"]["route"="road"]["name"~"^国道XXX号"];out tags;` を実行し、
その路線のリレーションが揃っているか確認してください。
取り直すときは `cache/rXXX.json` を消してから `fetch` します。

**交差点指定で「交差点が見つかりません」と出る**
全角と半角（`長沢（西）` と `長沢(西)`、`渚１丁目` と `渚1丁目`）は自動で吸収するので、
どちらで書いても構いません。それでも出ないときは地図上で名前を確認してください。

**市町村指定で「該当する区間がありません」と出る**
市町村名の綴りを確認してください（`長岡市` であって `長岡` ではない）。
平成の大合併前の自治体名は使えません。

**交差点指定で「経路が見つかりません」と出る**
海上区間（フェリー）や未開通区間で路線が分断されています。
メッセージに隙間の距離が出るので、数十m程度なら `GAP_BRIDGE_M` を上げれば繋がります。
km 単位なら本当に道が無いので、分断された側ごとに分けて指定してください。

**取得が途中で止まる／504や429が出る**
Overpass は無料の公開サーバなので、混雑すると 504（応答なし）や 429（レート制限）を返します。
これは想定内で、ツール側が自動で対処します。

- 429 を受けたらサーバに空き時刻を問い合わせて、その分だけ待ちます
- 504 が続いたミラーはしばらく使わず、別のミラーに回します
- エラーが出るとリクエスト間隔を自動で広げ、落ち着いたら元に戻します
- 取れなかったものは最後にまとめて再試行します（最大6巡）

途中でエラーが表示されても放置して構いません。1巡目で全部取れなくても、
最後に「すべて取得できました」と出れば完了です。

本当に取得できなかった路線があれば最後に一覧で表示されるので、
時間をおいて同じコマンドを実行してください。取得済みのぶんは飛ばされます。

Overpass 自体が停止している場合は、5件連続で失敗した時点で打ち切って知らせます。
数時間おいてから再実行してください。

**Ctrl+C で止めたい**
いつ止めても大丈夫です。取得済みのぶんは `cache/` に残るので、
同じコマンドで続きから再開します。

**59〜100号が空になる**
欠番なので正常です。
