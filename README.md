# 国道走破マップ

**地図を開いて、走った道をクリックするだけ**で走破記録がたまっていきます。
走破済み＝赤／未走破＝青で塗り分けた日本地図が、そのまま記録帳になります。

```
python kokudo_map.py serve
```

道路の形状は OpenStreetMap から取ってきて `cache/` に貯めます。
一度取得すればオフラインで何度でも地図を作り直せます。

Python 3.8 以降。追加ライブラリは不要です。

---

## 最初の1回

```
python kokudo_map.py init
```

`routes.csv`（記録の入れもの）が出来ます。中身はサンプルなので、
**見出しの行だけ残して他を消しておく**と、まっさらな状態から始められます。

次に全国道の形状を取得します。1〜507号を順に取るので **20〜30分ほどかかります**。
途中で止めても、もう一度同じコマンドを打てば続きから再開します。

```
python kokudo_map.py fetch --all
```

交差点名と道の駅（992駅）も同時に取ります。
これで準備は終わりです。あとは `serve` を使うだけです。

---

## 地図で記録する

```
python kokudo_map.py serve
```

ブラウザが開きます。**記録はすべてこの画面から行えます。**
書き込んだ内容はその場でファイルに保存されるので、保存操作は要りません。

### 終わりかた

**地図の右上の「終了」を押すか、ブラウザのタブを閉じるだけです。**
コマンドを実行した黒い画面は自動で閉じます。

| 操作 | 動き |
|---|---|
| 「終了」を押す | すぐ終わる。画面に「終了しました」が出る |
| タブを閉じる | 8秒ほどで終わる |
| 読み込み直す（F5） | 終わらない |
| 開いたまま放置 | 終わらない |
| Ctrl+C | 今までどおり終わる |

### 走った区間を記録する

1. 走り始めた地点を押す
2. その国道の行にある**「ここから」**を押す
3. 走り終えた地点を押して**「ここまで」**を押す

これだけです。その区間が赤くなり、走破率がその場で更新されます。

**押せる地点は2種類あります。**

**交差点名を押す** … 「交差点名を出す」にチェックを入れて拡大すると、
交差点名やIC名が出ます。名前を押すとその地点を通る国道が一覧で出ます。

```
日比谷  信号交差点
  国道1号    55.4 km   [ここから]
  国道20号   39.3 km   [ここから]
```

**線そのものを押す** … 名前が無い場所でも構いません。峠のてっぺんでも
県境でも、国道の線を直接クリックすればその地点を区間端にできます。

```
この地点を通る国道
  国道17号   一部走破  641 / 680 km   [ここから]
  国道18号   未走破      0 / 300 km   [ここから]
```

どちらの場合も、**重複区間では複数の国道が並ぶので、どの路線として
記録するかを選べます。** 始点と終点は同じ国道で揃えてください。

途中でやめたいときは、上部に出る帯の「やめる」を押します。

### 記録を直す・消す

右パネル上部の**「走破記録」タブ**に、これまでの記録がすべて並びます。

```
[290] R49×R290×R459@76.2〜R290端(南)@162.8
      2026/8/30              [編集] [削除]
```

- **記録の行を押すと、その区間だけが地図で光ります。** 他の路線は沈み、
  区間の距離が上部に出て、地図がその範囲に寄ります。もう一度押すと解除
- **編集** … 走破日とメモを書き換えられます。日付は自由記入なので
  `2026/8/30` でも `○` でも構いません
- **削除** … 確認のうえ消します。走破率もその場で戻ります

区間そのものは書き換えられません。間違えたときは削除して引き直してください。

### 道の駅

右パネルの「道の駅を出す」にチェックを入れると、丸で表示されます
（既定では非表示）。**丸を押して「行った」を押すだけ**で訪問済みになり、
その場で赤くなります。間違えたら「訪問を取り消す」で戻せます。

赤＝訪問済み、青＝未訪問。走破率の下に `道の駅 13 / 992 駅` と出ます。

## 地図の見かた

- 走破済みは赤、未走破は青。1本の国道の中でも走った部分だけが赤くなります
- 右パネルに距離ベースの走破率、全線走破本数、路線一覧
- **路線一覧の国道標識（おにぎり）を押すと、その路線だけが色濃く残って
  他が沈み、琥珀色の縁取りが付きます。** もう一度押すか Esc で解除
- 線をクリックすると、その地点を通る国道と走破状況が出ます

### 背景を変える

右パネル上部で、地図を開いたままいつでも切り替えられます。

| 背景 | 中身 |
|---|---|
| 白地図 | 海岸線・行政界・都道府県名・市区町村名のみ（既定） |
| 淡色地図 | 地名や高速道路も入った通常の地図 |
| 標準地図 | 地理院地図の標準表示 |
| 空中写真 | 航空写真 |
| 背景なし | 真っ白。国道の線だけが残る |

「濃さ」のスライダーで背景を薄くできます。「未走破の国道も描く」を外すと、
走った道だけが浮かび上がります。

なお白地図は z5〜z14 でしか配信されていないため、拡大しすぎると輪郭がぼやけます。
市街地を詳しく見るときは淡色地図に切り替えてください。

### 交差点名の印

点の色と形で種類が分かります。

| 印 | 種類 |
|---|---|
| 青い丸 | 信号交差点（OSM に登録されているもの） |
| 灰色の丸 | それ以外の名前付き地点 |
| 緑のひし形 | 国道どうしの交点（自動生成、全国 2,891 箇所） |
| 黒いひし形 | 路線の端（自動生成、1路線に2つ） |

OSM の交差点名は偏っていて、名前が4個以下しかない路線が37本あります。
そこで**国道どうしの交点と路線の端を自動で作って補っています。**
ひし形の2つは、名前が重なったときに丸より優先して表示されます。

名前のうしろに `R路線番号/端からのkm` が付きます。

```
四日町 R290/12.4              国道290号の、端から 12.4 km 地点
日比谷 R1/55.4 R20/39.3       2本が重なる地点
下三栖 R1/?                   路線が分断していて距離を測れなかった地点
```

3本以上が重なる地点は下に積んで表示します。
km は路線の端からグラフ上を辿った距離で、道路標識のキロポストとは一致しません。
同名の交差点を見分けるための番号だと思ってください。

### 表示の初期値を変える

毎回同じ設定にしたいときは `kokudo_map.py` の冒頭を書き換えてください。

```python
DEFAULT_BASEMAP = "blank"   # blank / pale / std / photo / none
BASEMAP_OPACITY = 0.55
SHOW_TODO = True
SHOW_NODES = True
SHOW_EKI = False   # 道の駅は既定で非表示
```

## 人に見せる1枚を作る

```
python kokudo_map.py build
```

`kokudo_map.html` が出来ます。**閲覧専用**（編集UIは付きません）ですが、
1枚で完結しているのでそのまま誰かに送っても見られます。
オフラインで開きたいときにも使えます。

（Leaflet と地図タイルはネット経由で読むため、閲覧時はオンラインである必要があります）

## CSV を直接編集する（任意）

**通常は必要ありません。** 地図の画面からすべて記録できます。

ただし記録は素直な CSV なので、まとめて書き足したいときや、
Excel で一覧したいときは直接編集しても構いません。
地図を開いたまま編集した場合は、`serve` を一度終了して開き直してください。

### routes.csv

| 列 | 内容 |
|---|---|
| 路線番号 | `17` / `R17` / `国道17号` のどれでも可 |
| 区間 | 下の4通り |
| 走破日 | 任意。空欄可 |
| メモ | 任意。地図のポップアップに出る |

```csv
路線番号,区間,走破日,メモ
17,全線,2024-05-03,
8,新潟県,2023-08-11,親不知
8,富山県高岡市,2023-08-12,
351,宮内〜与板橋,2025-06-01,
```

同じ路線を何行に分けても、まとめて1本として集計されます。

### 区間の書き方は4通り

| 書き方 | 例 | 粒度 |
|---|---|---|
| 全線 | `全線` | 路線まるごと |
| 都道府県 | `新潟県` | 県境で区切る |
| 市町村 | `新潟県長岡市` | 市町村界で区切る |
| 地点から地点 | `宮内〜与板橋` | いちばん細かい |

**都道府県指定と市町村指定は CSV でしか書けません**（地図の画面からは
地点どうしの指定になります）。県まるごと走ったときはこちらが手軽です。

都道府県名は必ず頭から書いてください（`長岡市` だけでは同名の判別ができません）。
`新潟県/富山県` のようにスラッシュでまとめ書きもできます。

指定した2点の間は、路線のネットワーク上の最短経路として計算されます。

### 使える地点の名前を調べる

```
python kokudo_map.py nodes 351
```

```
国道351号の名前付き地点 6 件（端から順）

  ●     6.1 km  宮内
  ●    62.2 km  中沢
  ●   104.6 km  本町
  ●   176.1 km  与板橋
  ・   219.3 km  川崎
  ●   284.2 km  本町
```

全件は `交差点一覧/国道351号.csv` にも出るので、Excel で開いて探せます。
自動生成した交点・端も含まれます。

### 同名の地点があるとき

上の例では `本町` が2か所あります。何も書かなければ経路が最短になる
組み合わせが選ばれ、その旨が警告に出ます。意図と違う場合は位置を添えてください。

```csv
351,本町@284.2〜川崎,,              端から284.2km地点のほうの本町
351,本町@35.3671/137.1049〜川崎,,   緯度経度で指定
```

### 名前の無い場所を指定する

緯度経度を直接書けます。最寄りの道路上の点に吸着します。

```csv
17,@36.74490/138.36520〜宮内,,     座標と名前を混ぜてもよい
451,R12×R451〜R275×R451,,          自動生成した交点どうし
290,R290端(北)〜R290端(南),,        端から端まで（ほぼ全線）
```

区切りは `/` と `,` のどちらでも通りますが、**手で書くときは `/` を使ってください。**
カンマだと CSV の列が割れて、`@36.74490` だけが残ってしまいます。

なお座標を調べる必要はありません。**地図で線をクリックして「ここから」を
押せば、この形が自動で書き込まれます。**

### 1つの地点に複数の呼び名が付くことがある

国道の終端が別の国道の途中と交わっていると、そこは交点でもあり端でもあります。
地図ではまとめて `R363×R419／R419端(北)` のように出ます。
**区間欄には `／` の前後どちらか一方だけを書いてください**（両方書くと一致しません）。

### michinoeki.csv

道の駅の記録です。**自分で作る必要はありません。** `build` や `serve` を
実行すると、取得済みの道の駅がすべて書き出された状態で用意されます。

```csv
都道府県,道の駅,訪問日,メモ
新潟県,あがの,2024/5/3,
新潟県,いりひろせ,,
```

**訪問日の欄を埋めた駅が「行った」扱い**になります。日付を覚えていないときは
`○` でも構いません。新しい道の駅が OSM に追加されると次回に行が足されます。
自分で書いた行が消えることはありません。

道の駅は OSM の `highway=services` / `rest_area` から拾っています。
全国で約1,230駅ありますが、OSM に登録されているのは1,000駅弱です。
足りない駅は自分で行を足せば一覧には載ります（座標が無いので地図には出ません）。

## 走破率の数え方

道路を細かい辺に分解し、走破した辺の集合として管理しています。そのため、

- 県指定と地点指定が重なっても二重計上されません
- 複数の国道が重複している区間も、全国の総延長では1回だけ数えます
- 「国道8号の47%」のような部分走破率がそのまま出ます

## コマンド一覧

```
python kokudo_map.py serve     地図を開く（記録はここから）
python kokudo_map.py build     閲覧用の kokudo_map.html を作る
python kokudo_map.py fetch     routes.csv に出てくる路線のデータを取得
python kokudo_map.py fetch --all   全国道のデータを取得（最初の1回）
python kokudo_map.py nodes 17  国道17号で使える地点名の一覧
python kokudo_map.py init      routes.csv のひな形を作る
```

`serve` は編集した1路線だけを計算し直すので待たされません。
全路線の再計算（起動時）は1分ほどかかります。

### なぜサーバが要るのか

`file://` で開いた HTML からはファイルに書き込めないという、ブラウザ側の制限です。
`serve` は 127.0.0.1（自分のパソコンの中だけ）で待ち受ける小さなサーバを立てて、
ブラウザからの保存要求を Python 側で受けて CSV に書きます。
**外部には公開されません。** ポートを変えたいときは `--port 8766` のように指定します。

## 調整できるところ

`kokudo_map.py` の冒頭にあります。

- `SIMPLIFY_TOLERANCE` — 線の間引き量。既定 0.0015（約150m）。
  小さくすると精密になりますがHTMLが重くなります
- `DEFAULT_BASEMAP` / `BASEMAP_OPACITY` / `SHOW_TODO` / `SHOW_EKI` — 初期表示
- `SHOW_NODES` / `NODE_MIN_ZOOM` / `LABEL_MIN_ZOOM` — 交差点名の初期表示と、
  点・名前が出はじめるズーム
- `DONE_COLOR` / `TODO_COLOR` / `SELECT_COLOR` — 走破済み・未走破・選択中の色。
  未走破を青にしているのは、白地図の市町村界（灰色の細線）と紛れないようにするため
- `PING_INTERVAL` / `BYE_GRACE` / `IDLE_TIMEOUT` — `serve` の自動終了。
  **`IDLE_TIMEOUT` を60秒より短くしないでください。** ブラウザは裏に回ったタブの
  タイマーを1分程度まで間引くので、短いと使用中に終了します
- `GAP_BRIDGE_M` — 行き止まりから道の途中までを何m まで繋ぐか。既定 50m。
  T字路の取りこぼしを拾うための値なので、大きくすると立体交差を掴みます
- `GAP_BRIDGE_END_M` — 行き止まり「どうし」を何m まで繋ぐか。既定 300m。
  上げると「距離不明」の地点が減ります（300m で全国 5.8%→3.9%、1km で 2.8%）
- `OVERPASS_ENDPOINTS` — 取得先のミラー。上から健全なものが選ばれます
- `REQUEST_INTERVAL` / `MAX_INTERVAL` — リクエスト間隔の下限と上限。
  混雑を検知すると自動で広がります。短くしないでください
- `ATTEMPTS_PER_TARGET` / `MAX_PASSES` / `PASS_COOLDOWN` — 再試行の粘り強さ
- `COORD_PRECISION` — 座標の突き合わせ桁数。既定7。変更しないでください

## うまくいかないとき

**地図で「ここから」を押しても何も起きない**
始点と終点は同じ国道で揃える必要があります。別の国道の「ここから」を
押すと、そちらが新しい始点になります。上部の帯で今どの路線を指定中か
確認できます。

**地点が「距離不明」と出る**
その地点が路線の分断された側にあり、端からの距離を測れていません。
**選べないわけではありません。** 「ここから」「ここまで」はそのまま使えて、
その場合はキロ程ではなく座標が書き込まれます。

**「経路が見つかりません」と出る**
海上区間（フェリー）や未開通区間で路線が分断されています。
メッセージに隙間の距離が出るので、数百m程度なら `GAP_BRIDGE_END_M` を
上げれば繋がります。km 単位なら本当に道が無いので、分断された側ごとに
分けて記録してください。

**特定の路線だけ線が出ない／短い／途切れ途切れになる**
OSM側のリレーションが未整備の可能性があります。
[overpass turbo](https://overpass-turbo.eu/) で
`rel["type"="route"]["route"="road"]["name"~"^国道XXX号"];out tags;` を実行し、
その路線のリレーションが揃っているか確認してください。
取り直すときは `cache/rXXX.json` を消してから `fetch` します。

**CSV に書いた交差点名が「見つかりません」と出る**
全角と半角（`長沢（西）` と `長沢(西)`、`渚１丁目` と `渚1丁目`）は自動で
吸収するので、どちらで書いても構いません。それでも出ないときは
地図上で名前を確認してください。

**CSV に書いた市町村が「該当する区間がありません」と出る**
市町村名の綴りを確認してください（`長岡市` であって `長岡` ではない）。
平成の大合併前の自治体名は使えません。

**取得が途中で止まる／504や429が出る**
Overpass は無料の公開サーバなので、混雑すると 504（応答なし）や
429（レート制限）を返します。これは想定内で、ツール側が自動で対処します。

- 429 を受けたらサーバに空き時刻を問い合わせて、その分だけ待ちます
- 504 が続いたミラーはしばらく使わず、別のミラーに回します
- 取れなかったものは最後にまとめて再試行します（最大6巡）

途中でエラーが表示されても放置して構いません。最後に「すべて取得できました」
と出れば完了です。取得できなかった路線は一覧で表示されるので、時間をおいて
同じコマンドを実行してください。取得済みのぶんは飛ばされます。

**Ctrl+C で止めたい**
いつ止めても大丈夫です。取得済みのぶんは `cache/` に残るので、
同じコマンドで続きから再開します。

**59〜100号が空になる**
欠番なので正常です。
